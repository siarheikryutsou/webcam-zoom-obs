# План: короткое демо-видео на сайт

Статус: **ждём запись от автора** (на 2026-11-23 видео ещё не записано).

## 1. Запись (автор)
- 20–30 секунд, без звука, максимальное качество. В кадре панель и превью сцены рядом.
- Сценарий:
  1. общий план;
  2. ЛКМ на лице, плавный зум;
  3. ведём мышь, рамка едет за ней;
  4. тянем рамку за ✥;
  5. ПКМ, отзум;
  6. переключаем сцену на маленькую камеру, там тот же зум;
  7. двойной клик, сброс.
- Исходник положить в `media-src/` (папка в `.gitignore`, в git не попадает).

## 2. Обработка (ffmpeg уже установлен через winget, Gyan.FFmpeg)
- `site/assets/demo.mp4` (H.264, `-movflags +faststart`) и `site/assets/demo.webm` (VP9): ширина 1280, без звука, цель до 3–4 МБ.
- `site/assets/demo-poster.jpg`: обложка из удачного кадра.
- `docs/demo.gif` до ~5 МБ для README (GitHub не проигрывает видео из репозитория).
- По необходимости обрезать начало и конец, ускорить скучные места.

## 3. Сайт (`site/index.html`, `site/ru/index.html`)
- Вместо `hero.svg` ставим `<video autoplay muted loop playsinline preload="metadata" poster>` с источниками webm и mp4. `hero.svg` остаётся запасным вариантом.
- При `prefers-reduced-motion` не запускать само: обложка и кнопка Play.
- Видео без текста, одно на обе страницы. Подпись под ним с шагами на языке страницы.
- JSON-LD `VideoObject` (name, description, thumbnailUrl, contentUrl, uploadDate, duration) на обеих страницах.

## 4. README
