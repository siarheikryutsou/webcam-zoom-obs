Привет! В соседнем проекте `H:\Work\webcam-zoom-obs\` уже сделано управление веб-камерой в OBS через **obs-websocket**. Твоя фича, похоже, подключается так же, так что не изобретай заново: возьми эту основу, а потом проекты, скорее всего, объединим.

**Прочитай сначала:** `H:\Work\webcam-zoom-obs\docs\OBS-CONNECTION.md` (схема, запросы, подводные камни), затем `H:\Work\webcam-zoom-obs\app.js`.

**Коротко:**
- OBS 28+ уже содержит WebSocket-сервер (v5, `ws://127.0.0.1:4455`, с паролем). Клиент: `obs-websocket-js` 5.0.6, браузерная сборка, файл `H:\Work\webcam-zoom-obs\vendor\obs-ws.global.min.js` (глобальный `OBSWebSocket`). Можно взять оттуда.
- UI — HTML-страница, подключённая как **Custom Browser Dock** (`file:///…/index.html`). Мышь работает только в доке, не в превью OBS и не в Browser Source.
- **Камеру напрямую (`getUserMedia`) не открываем**: её держит OBS. Кадры берём через `GetSourceScreenshot`, а картинкой в сцене управляем через `SetSceneItemTransform` (crop + bounds).
- Отправляем с троттлингом: одна команда в полёте и только при изменении. Анимация на `setInterval` 60 Гц.
- Исходный transform элемента сохраняется в `localStorage` и восстанавливается кнопкой.
